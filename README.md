# 電気使用申込書メーカー（東北電力向け）

東北電力ネットワークの「電気使用申込書」（従量電灯B 単独申込書 A-1、4ページ様式 D-1/E-1/F-1/I-1/J-1、公衆街路灯A B-1）を、
公式PDFを下敷きにしてブラウザ上で記入・作図し、A4のPDFとして書き出す単一HTMLツールです。

- 地図：国土地理院タイル（無料・APIキー不要）
- 動作：Safari / Chrome。iPadは Safari で開いて「ホーム画面に追加」
- 入力内容は各端末の中（localStorage / IndexedDB）にだけ保存されます。サーバには何も送りません。

使い方は画面内の案内に従ってください。公式PDFは東北電力のサイトからダウンロードして最初に1回読み込みます。
